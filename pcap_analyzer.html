How It Works

This tool demonstrates how OTPs can be extracted from packet captures:

Packet Inspection

Analyzes packet payloads to find OTP patterns in HTTP requests, responses, and other protocols.

TCP Stream Analysis

Reconstructs TCP streams to analyze complete sessions for OTP transmissions.

Protocol Filtering

Uses protocol-specific filters to focus analysis on traffic likely to contain OTPs.

Research Purpose Only: This tool is for educational and research purposes to understand how OTPs can be leaked in network traffic and implement better protection mechanisms.
Common PCAP Analysis Filters
Filter Description
http or https Shows HTTP and HTTPS traffic
http.request.method == "POST" Shows only HTTP POST requests
http contains "otp" Shows HTTP traffic containing "otp"
tcp.port == 25 or tcp.port == 587 Shows SMTP (email) traffic
gsm_sms Shows SMS messages (if available in capture)
